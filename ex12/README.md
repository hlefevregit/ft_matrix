# Exercice 12 — Matrice inverse

L’inverse d’une matrice A est une matrice A⁻¹ telle que :

A × A⁻¹ = I

où I est la matrice identité.

## Principe mathématique

La matrice identité fait “rien” :

I × x = x

Donc l’inverse permet d’annuler l’effet d’une transformation.

## Exemple

Pour une matrice d’échelle 2×2 :

A = [[2, 0], [0, 2]]

son inverse est :

A⁻¹ = [[0.5, 0], [0, 0.5]]

car on divise par 2 pour revenir à l’état initial.

## Condition

Une matrice n’a pas toujours d’inverse. Si son déterminant est nul, elle est singulière.
