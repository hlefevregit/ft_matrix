# Exercice 00 — Opérations élémentaires sur un vecteur

Un vecteur est une liste de nombres qui représente souvent une direction ou un déplacement.

Par exemple :

- u = (2, 3)
- v = (5, 7)

## Principe mathématique

### Addition

On additionne composante par composante :

u + v = (2 + 5, 3 + 7) = (7, 10)

Cela signifie que l’on combine deux déplacements.

### Soustraction

On soustrait aussi composante par composante :

u - v = (2 - 5, 3 - 7) = (-3, -4)

### Multiplication par un scalaire

Un scalaire est un nombre simple, par exemple 2.

2 × u = (2×2, 2×3) = (4, 6)

On “agrandit” ou “réduit” le vecteur sans changer sa direction.

## Ce que fait le code

Le programme applique ces règles à des vecteurs de taille 2.
