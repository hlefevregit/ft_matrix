# Exercice 11 — Déterminant

Le déterminant est un nombre associé à une matrice carrée.

## Principe mathématique

Pour une matrice 2×2 :

|a b|
|c d|

det = ad - bc

Pour 3×3, il existe une formule plus longue, mais l’idée reste la même : mesurer si la matrice “rétrécit”, “étire” ou “aplatit” l’espace.

## Intuition

- déterminant = 0 : la matrice détruit une dimension, elle n’est pas inversible,
- déterminant ≠ 0 : la transformation est inversible,
- le signe indique une inversion de sens.

## Exemple

[[2, 0], [0, 2]]

Le déterminant vaut 4 : tout est agrandi par 2 dans les deux directions.
