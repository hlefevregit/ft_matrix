# Exercice 15 — Nombres complexes et norme

Les nombres complexes sont de la forme :

z = a + bi

avec a partie réelle, b partie imaginaire.

## Principe mathématique

La multiplication complexe suit :

(a + bi)(c + di) = (ac - bd) + (ad + bc)i

## Norme d’un complexe

La norme d’un nombre complexe est :

|z| = sqrt(a² + b²)

C’est sa “taille” dans le plan complexe.

## Pourquoi c’est lié aux matrices ?

Dans de nombreuses applications, les nombres complexes servent à représenter des rotations, des signaux, des fréquences, et certains calculs matriciels.
