# Exercice 01 — Combinaison linéaire

Une combinaison linéaire consiste à prendre plusieurs vecteurs, les multiplier par des nombres, puis les additionner.

Exemple :

v = 10 × e1 - 2 × e2 + 0.5 × e3

où e1 = (1, 0, 0), e2 = (0, 1, 0), e3 = (0, 0, 1).

## Principe mathématique

On peut décomposer n’importe quel vecteur dans une base de référence.

Si l’on connaît les vecteurs de base, alors chaque vecteur peut s’écrire comme une somme pondérée :

x = a1.v1 + a2.v2 + ... + an.vn

Cela est très important en algèbre linéaire : on peut exprimer une information complexe comme une combinaison de directions simples.

## À retenir

- Les coefficients sont des nombres.
- Les vecteurs sont des directions.
- La combinaison linéaire mélange ces directions selon un poids.
