# Matrices et vecteurs — introduction progressive

Ce projet est une petite progression pour comprendre les concepts fondamentaux des mathématiques linéaires sans partir trop vite dans le formalisme.

## Idée générale

- Un vecteur est une liste de nombres. On peut le voir comme une direction dans l’espace.
- Une matrice est un tableau de nombres organisé en lignes et colonnes.
- Les opérations ne sont pas “magiques” : elles répétent simplement des calculs utiles pour transformer des directions, mesurer des angles, résoudre des systèmes, ou projeter des objets.

## Progression des exercices

1. Opérations simples sur les vecteurs
2. Combinaison linéaire et interpolation
3. Produit scalaire
4. Normes et longueurs
5. Angle entre deux vecteurs
6. Produit vectoriel
7. Multiplication matrice-vecteur et matrice-matrice
8. Trace d’une matrice
9. Transposée
10. Échelonnement de lignes
11. Déterminant
12. Matrice inverse
13. Rang
14. Projection 3D
15. Nombres complexes et norme

Chaque exercice a son propre fichier README dans le dossier correspondant.
