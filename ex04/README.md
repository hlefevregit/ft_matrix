# Exercice 04 — Normes d’un vecteur

La norme d’un vecteur correspond à sa longueur.

## Principe mathématique

Pour un vecteur u = (x, y, z), la norme euclidienne est :

||u|| = sqrt(x² + y² + z²)

C’est la distance entre l’origine et le point représenté par le vecteur.

### Autres normes

- Norme 1 : somme des valeurs absolues
  ||u||1 = |x| + |y| + |z|

- Norme infinie : plus grande valeur absolue
  ||u||∞ = max(|x|, |y|, |z|)

## Exemple

u = (1, 2, 3)

||u|| ≈ 3.74

## Pourquoi c’est important ?

La norme permet de comparer des longueurs, normaliser des vecteurs, et calculer des distances.
