# Exercice 03 — Produit scalaire

Le produit scalaire mesure la “similarité” entre deux vecteurs.

## Principe mathématique

Pour u = (u1, u2) et v = (v1, v2) :

u · v = u1v1 + u2v2

On multiplie les composantes correspondantes puis on additionne.

### Exemple

u = (1, 1)
v = (1, 1)

u · v = 1×1 + 1×1 = 2

## Intuition

- Si deux vecteurs pointent dans la même direction, le produit scalaire est grand.
- S’ils sont perpendiculaires, il est nul.
- S’ils sont opposés, il est négatif.

C’est un outil central pour mesurer des angles et des projections.
