# Exercice 08 — Trace d’une matrice

La trace d’une matrice carrée est la somme des termes de la diagonale principale.

## Principe mathématique

Pour une matrice A :

tr(A) = a11 + a22 + ... + ann

## Exemple

A = [[1, 0], [0, 1]]

tr(A) = 1 + 1 = 2

## Intuition

La trace ne regarde que les éléments qui “se trouvent sur la diagonale”.

C’est souvent utile dans les calculs de rotation, de stabilité et de changement de base.
